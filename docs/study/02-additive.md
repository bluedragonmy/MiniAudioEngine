# 第 2 關：加法合成（AdditiveOscillator）

檔案：`cpp/src/AdditiveOscillator.cpp`

## 先懂這幾個詞（白話版）

- **第 k 個泛音 = 基音 × k**。基音 200 Hz：第 3 個 = 600 Hz，第 5 個 = 1000 Hz。
- **「第 k 個」是門牌號碼，不是排隊順序**。方波、三角波把偶數號的房子拆了，但 3 號還是叫 3 號；被拆掉的房子音量是 0。
- **算某個泛音多大聲，固定兩步**：
  - A：這間房子還在嗎？（k 是奇數還是偶數、這個波形有沒有用到）
  - B：在的話，代公式（鋸齒、方波：1/k；三角：1/k²）
  - 例：三角波第 3 個 → 奇數，在 → 1/9；第 2 個 → 偶數，不在 → 0
- **能疊幾個泛音**：一個一個列出來，跟 **Nyquist（取樣率 ÷ 2）** 比，不是跟取樣率比。**剛好等於 Nyquist 也不行。**
  - 5000 Hz @ 48 kHz：5k、10k、15k、20k ✅，25k ❌ → 4 個
  - 8000 Hz @ 48 kHz：8k、16k ✅，24k（等於）❌ → 2 個

## 原理

**傅立葉的發現**：任何重複的波形，都可以拆成一堆正弦波的和，這些正弦波的頻率是基音的整數倍（泛音）。

反過來說，只要知道「每個泛音要多大聲」，就能把波形疊回來。這就是加法合成：

```
輸出 = Σ (第 k 個泛音的振幅) × sin(k × phase)
```

三種經典波形的「食譜」（`harmonicAmplitude()`）：

| 波形 | 第 k 個泛音的振幅 | 白話 |
|---|---|---|
| 鋸齒波 | (2/π) · (−1)^(k+1) / k | 全部都有，越高越小（1/k） |
| 方波 | (4/π) / k，只有奇數 k | 只有奇數，1/k |
| 三角波 | (8/π²) · (±1) / k²，只有奇數 k | 只有奇數，衰減更快（1/k²） |

正負號代表相位（往上還是往下起跳）。三角波的泛音以 1/k² 衰減，所以第 3 個泛音只有 1/9，聽起來比方波柔和很多。

### 為什麼不直接算鋸齒波？

最直覺的鋸齒波是 `2 * (phase / 2π) − 1`，一行就寫完。但這個波有**瞬間的跳變**，跳變包含無限高的頻率，超過 Nyquist 的部分就會 alias（第 2 章！）。

加法合成只疊 Nyquist 以下的泛音，所以**天生不會 alias**，這叫 band-limited。代價是比較耗運算（每個取樣要算幾十次 sin）。

## 程式碼導讀

| 行 | 在做什麼 |
|---|---|
| `harmonicAmplitude()` | 上面那張表 |
| `activeHarmonics()` | 算出 Nyquist 以下最多能有幾個泛音：`ceil((sr/2) / f) − 1`，再跟 `maxHarmonics` 取小 |
| `process()` | 迴圈疊加 `a * sin(k * phase)`，然後 phase 前進，跟你的 `Oscillator` 一模一樣 |

`activeHarmonics()` 的 `ceil(...) − 1`：要求 `k·f < sr/2`（嚴格小於，剛好等於 Nyquist 也不行）。例如 48 kHz、6 kHz：`24000/6000 = 4`，`ceil(4) − 1 = 3`，第 4 個泛音剛好在 24 kHz 被排除。

## 測試在驗證什麼

| 測試 | 意義 |
|---|---|
| `saw at 1/4 cycle = 0.5` 等三個 | 傅立葉級數在 x = π/2 有已知的值。疊 2001 個泛音後應該非常接近 |
| `band-limit: 5 kHz @ 48k keeps 4 harmonics` | 5、10、15、20 kHz 都在 24 kHz 以下，25 kHz 超過 |
| `6 kHz excludes harmonic at Nyquist` | 邊界條件：剛好等於 Nyquist 要排除 |
